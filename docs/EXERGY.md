# Exergy

**Remaining useful work** — native Apple usage tracker for AI coding accounts.

Exergy lives in [ShannonUI `Exergy/`](https://github.com/LeBonhommePharma/ShannonUI) as a second App Store product (bundle IDs `com.lebonhommepharma.exergy.*`). Shannon CLI stays headless. Shannon UI's pill can show an Exergy glance chip from App Group JSON (`remaining % left`); it never reads Exergy tokens.

Shannon measures entropy collapse (`ΔH < −3.2 bits`). Exergy measures remaining plan quota. Same family, different instrument.
